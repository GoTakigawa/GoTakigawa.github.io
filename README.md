# GTI / Fretboard Tools

ギターやベースのマルチスケール指板設計・テンション計算を行うためのウェブアプリケーションです。

## ローカルでの動作確認方法

このプロジェクトには、ブラウザのセキュリティ制限（CORS）を回避して `localhost` で動作確認するための方法がいくつか用意されています。

### 方法1：バッチファイルを使用する（推奨・最も簡単）
プロジェクトのルートディレクトリにある `devserver.bat` をダブルクリックしてください。
- `http://localhost:8000` でサーバーが起動します。
- ブラウザを起動し、上記URLにアクセスしてください。
- 終了するには、コマンドプロンプトを閉じるか `Ctrl + C` を押してください。
- ※実行には Python がインストールされている必要があります。

### 方法2：VS Code の拡張機能を使用する（開発者向け）
VS Code をお使いの場合は、拡張機能 **「Live Server」** (by Ritwick Dey) の利用をおすすめします。
- 拡張機能をインストール後、右下の `Go Live` ボタンを押すだけでサーバーが立ち上がります。
- ファイルを保存すると自動的にブラウザがリロードされるため、非常に効率的です。

### 方法3：Node.js (npm) を使用する
Node.js がインストールされている場合は、以下のコマンドで起動できます：
```bash
npx serve
# または
python -m http.server 8000
```

## 主要ファイル構成
- `index.html`: メインアプリケーション（指板ジェネレーター）
- `tension_calculator.html`: テンション計算機
- `tension-calc.js`: テンション計算ロジック
- `tunings_unified.json`: チューニングデータ
